# Errands

Daily and weekly quests for Minecraft Paper servers. Players get random quests from pools you
configure, see them in a menu (`/quests`), and claim rewards: items, XP, Vault money and console
commands.

Errands runs on **Paper 1.21.4–26.2** (tested on 1.21.11 and 26.2; Folia supported, tested on Folia 1.21.11) with **Java 21 or newer**. It does **not**
run on Spigot or CraftBukkit. There is no license key and no DRM.

## Support

Bug reports and questions go to the issues repository:
https://github.com/pkerpo/errands-issues/issues

Please read the [FAQ](wiki/FAQ.md) first, and include your server version (`/version`), the Errands version
(`/errands info`) and the relevant part of the console log.

## A note on selling

Please do not sell extra rerolls or quest rewards for real money. See
[Commands and Permissions](wiki/Commands-and-Permissions.md#please-do-not-sell-rerolls-or-rewards-for-real-money).
